Como levar para o CapCut
CapCut PC:
  1. Clique em “Abrir pasta de saída”.
  2. Arraste o vídeo _cortado.mp4 (ou a pasta _clipes) para a área de mídia do CapCut.
  3. Coloque na timeline e finalize: legendas automáticas, música, efeitos.
CapCut celular:
  1. Inicie o programa com INICIAR-COM-CELULAR no PC.
  2. Abra o link do celular mostrado no topo (mesmo Wi-Fi).
  3. Toque em “Baixar” no resultado; o vídeo vai para a galeria/arquivos.
  4. No CapCut: Novo projeto → escolha o vídeo baixado.
Os arquivos saem em MP4 (H.264 + AAC, quadros constantes), o formato que o CapCut abre sem converter.
